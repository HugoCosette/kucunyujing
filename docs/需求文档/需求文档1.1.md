# 布料库存规划需求 1.1

> ⚠️ 本文件记录的是 1.1 时期（模式 → 评分档 → 周倍数系数）的口径。**2026-11-10 起已按 [需求文档1.5.md](./需求文档1.5.md) 重构**：评分因子、评分档与校准全部删除，改为「月均条数 → 5 个模式 → 系数」。当前口径以 [模式与系数设置.md](./模式与系数设置.md)、[需求文档1.5.md](./需求文档1.5.md) 为准，下文中「评分」「评分档」「等级」相关描述均已作废。

## 1. 备货模式

计算因子全部取自导入列（1-12 月销售数据不参与任何因子）：总表提供 唯一标识 / 品名 / 颜色 / 色彩 / 生产中 / 欠货 / 周消耗 / 周转入 / 在途库存 / 在仓库存 / 总出库数量；销售表提供 唯一标识 / 品名 / 颜色 / 月均条数 / 订单总数 / 动销月份 / 累计客户。两张表按「唯一标识」关联同一个 SKU。

备货判定先分**策略**，再进各自的分层：

1. **自动策略**（默认）：模式 → 评分档 → 系数（下述 1～3 层）。
2. **手动策略**：人工为指定 SKU 选一个「手动模式」，不走模式匹配与评分。
   - **自定模式**：直接给该 SKU 指定红线 / 正常 / 峰值系数（未填时用该模式的默认系数）。
   - **滞销模式**：不参与备货——三档库存与系数显示「滞销」，预警灰且不计入四色统计，不进紧急补货，无建议值，缺口量/缺口率/库销比显示 `—`；仍可人工采纳需安排。
   - 手动模式的行为由系统提供（自定系数 / 滞销），名称、说明与默认系数可在配置页自行调整，也可新增模式（选择已有行为），无需改代码。
   - 策略入口在 SKU 弹窗（主面板与销售表共用）：「策略」区切换自动 / 手动，选回自动即清除该 SKU 的手动设置。
   - 手动归属记录在独立文件 `src/stocking/manualSkus.json`（按唯一标识），跨导入、跨刷新保留；配置页「手动策略」页汇总全部手动 SKU，可直接改模式 / 改系数 / 恢复自动，并提示已不在当前数据中的悬空记录。

自动策略的分层：

1. **模式层**：可配置「模式1、模式2……」，每条模式由若干「模式因子」组成，同一模式内全部条件满足才算命中。模式按设计互斥（一个 SKU 只属于一条模式），都不命中时归入固定末位的「兜底模式」（无条件命中）。
   - 模式因子字段可选全部导入列：数值字段支持 `≥ / ≤ / =`，`色彩` 只能 `= 黑白/彩色`，`品名`/`颜色` 只能精确匹配，`唯一标识` 仅作关联键、不可作因子。
   - 同字段可加多条条件表达区间（如 订单总数 ≥ 100 且 ≤ 199）。
   - 未配置模式因子的非默认模式不参与匹配；配置时提示区间重叠，并用实际数据列出命中多条模式的 SKU。重叠不阻断保存，运行时按模式列表中靠前的模式处理并在主表标记。
2. **评分层**：每条模式可自由启用评分因子（限数值字段，常用 4 个动销指标），并为每个因子配置 S / A / B / C 四档阈值（统一 `≥`，须从 S 到 C 递减）。
   - 取该因子满足的最高等级；未达 C 阈值、缺值或缺列一律记 Z。
   - 计数只看本模式启用的因子，Z 同样参与计数。
   - 每条模式可配置若干「评分档」，条件形如「S ≥ 2」「C ≥ 2」，同档内为 AND，按档位顺序取第一个命中的档；末位固定「默认档」无条件兜底。
   - 档名自由（热销A、热销B、热销J……）。
3. **系数层**：每个「模式 × 评分档 × 色彩类别（黑白/彩色）」维护红线 / 正常 / 峰值三个系数（单位：周），要求 红线 ≤ 正常 ≤ 峰值。

红线、正常、峰值库存分别为周消耗乘以对应系数。周消耗为 0、色彩为空或系数缺省时按「模式缺省」处理，不计算四色预警。

### 1.1 默认配置

| 模式 | 命中条件 | 评分因子与阈值 | 档位 | 系数（黑白 / 彩色） |
|---|---|---|---|---|
| 模式1 | 月均条数 ≥ 200 且 订单总数 ≥ 10 | 月均条数 S120/A90/B30/C1、订单总数 S100/A50/B20/C1 | 热销A（S ≥ 2） | 3/5/8、2/4/6 |
| 模式1 | 同上 | 同上 | 默认档（兜底） | 2/4/6、2/4/6 |
| 默认模式 | 无条件 | 月均条数 S120/A90/B30/C1 | 默认档（兜底） | 2/4/6、2/4/6 |

未导入 Excel 时，演示数据按周消耗折算出一组动销指标，保证模式与评分分档在种子数据上同样可见。

### 1.2 配置的读写与生效

- 配置以 `src/stocking/config.json` 为唯一来源，由 `src/stocking/` 模块统一读取、校验与计算；文件为多方案结构（`profiles[]` + `activeProfileId`），同一时刻只有当前方案参与计算。
- 「配置信息」与「示例配置」共用同一份方案文件，任一处修改对两页同时生效；但生产数据与演示数据应各用一个方案（如「生产配置」「演示配置」），切换方案即可整体换阈值与系数，互不覆盖。
- 配置页支持按当前已导入数据校准评分阈值（S≈前 10% / A≈前 30% / B≈前 60%，C 固定 0），校准只改草稿，保存后生效。
- 点击「确定」先做结构校验（名称唯一、阈值递减、系数非负且 红线 ≤ 正常 ≤ 峰值），通过后写回源文件；开发态由 Vite 插件直接落盘并屏蔽该文件的 HMR（避免刷新丢掉已导入数据），构建产物无法写盘时保存到浏览器本地缓存，可「导出配置」手动覆盖源文件。
- 「恢复默认」用模块内置的默认配置覆盖并写回。
- 删除模式需二次点击确认；档位 / 因子 / 条件的删除可直接操作，靠配置页底部的「撤销 / 重做」回退（历史只覆盖未保存的草稿，确定、重置、恢复默认后清空）。

## 2. 表头分组与数量关系

主表表头按业务流向分组，依次为：信息 → 商品 → 入口 → 出口 → 库存 → 数据反馈；备货策略列在配置信息页展示，导出时追加在末尾。

「信息」分组依次展示模式、评分档（档位名称，悬停显示等级明细，如 `SSAZ`）；模式与评分档由备货配置计算，不参与导入。**唯一标识只作为总表与销售表的关联键，界面任何表格都不显示该列**（导入模板与 Excel 导出仍保留，保证导出文件可直接回导）。

主面板的数据以 Excel 导入为主要来源（见第 7 节）：品名、颜色与入口 / 出口 / 库存中的数量列（含在途库存）全部由导入文件提供，面板内一律只读、不可点击修改；整张表只有「需安排」可在面板内维护（采纳 / 撤销 / 批量补货），它不参与导入。预警灯、理论库存、预计库存、缺口量、缺口率、库销比、红线/正常/峰值库存始终由系统计算，导入文件中的同名列会被忽略。

| 分组 | 字段 | 类型 | 取值/计算 |
|---|---|---|---|
| 信息 | 唯一标识 | 导入项 | 总表与销售表的关联键，**界面不显示**，只参与导入关联与导出文件 |
| 信息 | 模式 | 计算项 | 命中的模式名称；命中多条时按列表靠前处理并标记 |
| 信息 | 评分档 | 计算项 | 命中的评分档名称 |
| 商品 | 品名 | 导入项 | 只读；颜色子行在品名列重复显示所属品名 |
| 商品 | 颜色 | 导入项 | 只读；仅颜色子行显示 |
| 商品 | 预警 | 计算项 | 由预计库存与红线/正常/峰值库存比较得出 |
| 入口 | 需安排 | 编辑项 | 空值按 0；采纳后叠加进预计库存，从而影响预警、缺口量与缺口率 |
| 入口 | 生产中 | 导入项 | 只读，直接取值 |
| 出口 | 欠货 | 导入项 | 只读；仅记录展示，不参与任何数量计算 |
| 出口 | 周消耗 | 导入项 | 只读；备货策略各库存的计算基数 |
| 库存 | 在仓库存 | 导入项 | 只读，直接取值，参与理论库存与库销比 |
| 库存 | 周转入 | 导入项 | 只读，直接取值，默认 0；仅记录展示，暂不参与理论库存与预警计算 |
| 库存 | 在途库存 | 导入项 | 只读；由导入文件提供，可空（按 0）；参与理论库存计算 |
| 库存 | 理论库存 | 计算项 | 在仓库存 + 在途库存（事实层，不含计划） |
| 库存 | 预计库存 | 计算项 | 理论库存 + 需安排（空按 0）；评估层，预警与缺口的判定基数 |
| 数据反馈 | 缺口量 | 计算项 | 正常库存 − 预计库存；模式缺省时为“缺省”，可为负（负值表示超出正常库存） |
| 数据反馈 | 缺口率 | 计算项 | 缺口量 ÷ 正常库存 × 100%；模式缺省或正常库存为 0 时为空（显示“--”） |
| 数据反馈 | 库销比 | 计算项 | 在仓库存 ÷ 周消耗；周消耗为 0 时为空（显示“--”） |
| 备货策略 | 红线库存 | 计算项 | 周消耗 × 红线系数 |
| 备货策略 | 正常库存 | 计算项 | 周消耗 × 正常系数 |
| 备货策略 | 峰值库存 | 计算项 | 周消耗 × 峰值系数 |
| 备货策略 | 系数 | 计算项 | 红线/正常/峰值系数，模式缺省时显示“缺省” |

数量关系链：

1. 周消耗 × 各系数 → 红线库存、正常库存、峰值库存。
2. 在仓库存 + 在途库存 → 理论库存（在途库存由导入/录入提供，需安排不参与该步）。
3. 理论库存 + 需安排（空按 0）→ 预计库存。
4. 预计库存 与 红线/正常/峰值库存比较 → 四色预警（见第 1 节）。
5. 正常库存 − 预计库存 → 缺口量；缺口量 ÷ 正常库存 → 缺口率。
6. 在仓库存 ÷ 周消耗 → 库销比。

品名父行的汇总模式：

- 只汇总当前可见的子行；需安排空值按 0 累加，其余数值字段在子行均为有效数值时求和，否则显示“缺省”。
- 红线库存、正常库存、峰值库存、预计库存、缺口量仅在子行模式全部可用时求和；父行缺口率、库销比按汇总后的值重新计算。
- 父行不显示预警灯。

数值显示模式：整数原样显示，非整数保留两位小数；模式缺省的数量显示“缺省”，无法计算的比率显示“--”。

## 3. 库存表与配置

- 主表按品名（SPU）分组，品名父行可折叠/展开颜色 SKU 子行；父行展示可见子行的汇总。
- 库存日常操作放在主面板；色彩类别仍随导入维护，模式 / 评分档 / 系数在配置信息页维护，两页共享同一份备货配置。
- 顶部导航左侧为主面板组（主面板、配置信息），右侧为示例数据组（示例面板、示例配置）；示例数据组仅用于对照演示，不作为需求迭代目标。
- 主面板与示例面板结构、计算和交互完全一致，但库存、需安排采纳、撤销状态和采购清单各自独立；“配置信息”页只维护主面板数据，“示例配置”页只维护示例面板数据，两者互不影响。
- 在途库存、理论库存、预计库存的计算口径见第 2 节；“已安排”字段及列已移除。
- “库存”分组依次展示在仓库存、周转入、在途库存、理论库存和预计库存。
- 预设商品的需安排初始为空，空值按 0 计算。
- 预警只以 SKU 的已采纳库存计算，采用色块显示，不在灯旁显示状态文字：
  - 红：预计库存低于红线，紧急补货。
  - 紫：预计库存高于峰值，降低库存。
  - 绿：预计库存位于正常库存的 80% 至 120%（含边界），无需补货。
  - 黄：其他可计算状态，常规补货。
  - 灰：模式缺省，不参与四色筛选。

## 4. 筛选

- 支持品名、颜色关键词筛选，以及按模式、评分档多选筛选；红、黄、绿、紫预警状态可多选。同一类筛选项之间为「或」，不同类之间为「且」。
- 筛选只影响表格展示；紧急补货清单和库存 Excel 导出仍使用全量 SKU。

## 5. 需安排与补货

- 需安排输入先作为草稿；草稿本身不改变实际库存与统计数据，但会按“理论库存 + 草稿”预览该行在采纳后的预警色。
- 点击“采纳”后写入需安排值，预计库存随之抬高，预警、缺口量与缺口率同步更新；采纳后输入框锁定，按钮变为“撤销”。需安排不写回在途库存。
- 撤销恢复采纳前的数值（原值为空则恢复为空），预计库存与预警同步回落，同时解锁输入框。紧急补货提交同样保存可撤销快照。
- 主表提供紧急补货弹窗，记录新增计划数量；确认后累加到需安排，不覆盖原值。
- 需安排建议值 = max(当前需安排（空按 0）, 0, ⌈正常库存 × 80% − 理论库存⌉)，仅作为输入提示，不自动采纳。

## 6. 本次采购清单与导出

- 主表采纳需安排或紧急补货确认后，将 SKU 同步加入“本次采购清单”；同一 SKU 只保留一行，后续提交更新需安排数。
- 撤销库存变更时同步恢复或移除对应清单记录。
- 清单显示品名、颜色、需安排和实际计划；实际计划初始为空，可填写，且不参与库存计算。
- 清单可导出为 XLSX；表头浅色底、深色字，单元格内容统一居中。
- **待确认：**是否需要将采购清单按具体工厂拆分/分配，以及工厂信息来源和维护方式。

## 7. 主面板 Excel 导入

主面板库存数据以 Excel 导入为准；示例面板不提供导入入口。

### 7.1 导入模板

按「唯一标识」识别 SKU，模板列如下（“导入模板”按钮可直接下载带示例行的模板）：

| 列 | 必填 | 说明 |
|---|---|---|
| 唯一标识 | 是 | SKU 关联键，与销售表同名同值；缺失或重复的行判为错误行 |
| 色彩 | 否 | 黑白 / 彩色；留空视为模式缺省 |
| 品名 | 是 | 去除空格后作为 SPU 名称 |
| 颜色 | 是 | SKU 颜色（仍做“品名+颜色重复”校验，但不作为关联键） |
| 生产中 | 否 | 空值按 0 |
| 欠货 | 否 | 空值按 0，仅记录展示 |
| 周消耗 | 否 | 空值按 0，备货策略的计算基数 |
| 在仓库存 | 否 | 空值按 0 |
| 在途库存 | 否 | 空值按 0；参与理论库存计算 |
| 周转入 | 否 | 空值按 0，仅记录展示 |
| 总出库数量 | 否 | 空值按 0；只作为模式因子/评分因子，不参与库存公式 |

动销指标（月均条数 / 订单总数 / 动销月份 / 累计客户）只来自销售表；总表若带同名列，预览会提示该列被忽略。

- 模式与评分档不参与导入，导入后按 `src/stocking/config.json` 计算；文件带“评分档”（旧模板为“热度”）、“备货类型”列时预览会提示该列被忽略。
- 需安排不参与导入，继续由面板内的采纳/撤销维护；文件带“需安排”列时预览会提示该列被忽略。
- 理论库存、预计库存、缺口量、缺口率、库销比、红线/正常/峰值库存、系数与预警灯由系统计算，导入文件中的同名列忽略。
- 表头需包含“品名”和“颜色”，可位于前 10 行任意一行；“保存Excel”导出的两行分组表头可直接再次导入。
- 列顺序不限，数值可带千分位分隔符；主面板只取上述字段，其余列不参与计算。
- 4 个动销指标（月均条数 / 订单总数 / 动销月份 / 累计客户）只来自销售表，是模式因子与评分因子的常用来源；总表带同名列时忽略。

### 7.2 导入行为

- 一次导入两个来源表，且必须同时选择总表 + 销售表（可多选、顺序不限）：只选一个或表头缺少唯一标识都会阻止导入。
- 总表整表替换：确认后主面板库存行全部替换为总表数据。
- 销售表叠加：按「唯一标识」把 1-12 月条数与重量叠加到对应 SKU，并用其 4 个动销指标写入主面板行，随后按备货配置重算模式、评分档与系数；销售表缺列或空值的指标记为空（评分记 Z）。
- 总表与销售表按唯一标识关联，不再使用“品名 + 颜色”：改品名或补色号不会丢失需安排、撤销快照与采购清单。
- 主面板表格采用滚动虚拟化，只渲染视口内的行，3 万行量级也不会一次性创建大量节点。
- 需安排、撤销快照和本次采购清单按唯一标识保留；Excel 中不再存在的 SKU，其需安排与清单记录一并移除。
- 只支持 .xlsx（单个文件不超过 50MB），读取第一张工作表。
- 确认前展示预览：总表与销售表分别给出有效行数、忽略的空行数、错误行数及逐行原因；未识别的文件单独列出。错误行不静默丢弃，修正后可重新导入。
- 错误情形：唯一标识为空或重复、品名或颜色为空、品名+颜色重复、数值列不是有效数字、色彩不在枚举内。
- 导入结果只保存在页面运行期间，刷新后恢复预设数据。

### 7.3 销售表：1-12 月销售数据 + 动销指标

- 销售表 `/sales` 展示品名、颜色与 1-12 月销售数据：品名、颜色来自主面板，4 个动销指标（月均条数 / 订单总数 / 动销月份 / 累计客户）随销售表导入。
- 列固定为：品名、颜色、月均条数、订单总数、动销月份、累计客户、1月条数、1月重量、2月条数、2月重量……12月条数、12月重量，共 30 列；动销指标与月份列之间用粗竖线分隔。唯一标识只用于与总表关联，不在本页显示。
- 销售表的动销指标是评分因子的唯一来源：写回主面板并按备货配置重算；缺列或空值时该指标记为空（评分记 Z），不再回退到总表。
- 只叠加主面板已有的唯一标识：未匹配的行跳过，导入预览给出跳过行数与示例；错误行（唯一标识为空/重复、品名/颜色为空、条数/重量不是有效数字）逐行提示且不导入。
- 月份列可缺省（如只导出 2-10 月）：缺列或空值的月份在表格中显示为空；文件未提供重量的月份，重量列同样为空。
- 以最新文件为准：每次确认导入同时替换总表库存行与销售表数据；需安排、撤销快照与采购清单按唯一标识保留，Excel 中不存在的 SKU 一并移除。
- 按品名（SPU）汇总：品名父行显示该品名各数值列的合计，同品名的颜色行折叠在父行下，默认展开，点击父行可收起；搜索框检索全部列，过滤后父行只统计命中的行。
- 表格沿用 3 万行滚动虚拟化，只渲染视口内的行；销售表数据只保存在页面运行期间，刷新后回到“未导入销售表”状态。

## 8. 数据与保存范围

- 当前使用模拟库存数据；每个面板（主面板、示例面板）的库存、采购清单与撤销状态在页面运行期间各自独立，备货配置全应用共用一份。
- 主面板单次导入可支撑 3 万行以上（实测 3 万行约 1.5 秒可用，滚动与筛选保持流畅）；单文件上限 50MB。
- 配置信息页仍是 Element Plus 常规表格：库存记录超过 500 行时改为扁平分页（每页 60 行），不超过 500 行时保持按品名分组的树形展示。
- 切换主面板、配置信息、示例面板与示例配置不丢失当前运行数据；刷新页面恢复初始示例数据。
- 示例面板与示例配置内的数据固定作为示例，后续需求调整只在主面板与配置信息中实施。
- XLSX 导出为下载副本，不是持久化存储，也不能自动回写系统数据。
