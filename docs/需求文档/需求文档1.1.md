# 布料库存规划需求 1.1


## 1. 备货规则

按“热度 × 色彩类别”读取红线、正常和峰值系数，系数单位为周，不再使用旧等级（SS、S、A）。

| 热度 | 色彩类别 | 红线 | 正常 | 峰值 |
|---|---|---:|---:|---:|
| 热销 | 黑白 | 3 | 5 | 8 |
| 热销 | 彩色 | 2 | 4 | 6 |
| 常规 | 黑白 | 2 | 4 | 6 |
| 常规 | 彩色 | 2 | 4 | 6 |

红线、正常和峰值库存分别为周消耗乘以对应系数。系数按热销/常规分类调整；没有匹配规则时按规则缺省处理，不计算四色预警。

热度不再取自 Excel 或种子数据，而是在“配置信息 → 热度配置”中按导入的数值字段判定：

- 热销配置、常规配置各维护一组因子条件，因子来源为导入的数值列（生产中、欠货、周消耗、在仓库存、在途库存、周转入等），新增列会自动出现在可选项。
- 每个因子由“数值字段 + 比较符（≥ / ≤）+ 阈值”组成，同一配置内全部条件满足才算命中。
- 默认启用“生产中”“周消耗”两个因子，其余因子通过“＋ 添加因子”加入；修改后需点击“确定”才生效。
- 判定口径为热销优先：满足热销全部条件即为热销，其余一律常规。热度配置暂仅保存在页面运行期间，刷新后恢复默认配置。
- 默认阈值：热销为生产中 ≥ 500 且周消耗 ≥ 700；常规为生产中 ≥ 0 且周消耗 ≥ 0。

系数不再固定在 stockingRules 中，而是在“配置信息 → 系数配置”中按“热度 × 色彩类别”四组维护红线 / 正常 / 峰值三个系数（单位：周），默认取当前 stockingRules 的值；修改后点击“确定”统一生效，暂仅保存在页面运行期间。

## 2. 表头分组与数量关系

主表表头按业务流向分组，依次为：商品 → 入口 → 出口 → 库存 → 数据反馈；备货策略列在配置信息页展示，导出时追加在末尾。

主面板的数据以 Excel 导入为主要来源（见第 7 节）：品名、颜色是基本信息，入口、出口与库存中的输入项（含在途库存）由导入文件提供，导入后仍可在面板内临时修改；需安排只在面板内维护（采纳/撤销），不参与导入。预警灯、理论库存、预计库存、缺口量、缺口率、库销比、红线/正常/峰值库存始终由系统计算，导入文件中的同名列会被忽略。

| 分组 | 字段 | 类型 | 取值/计算 |
|---|---|---|---|
| 商品 | 品名 | 编辑项 | 父行可编辑品名；颜色子行在品名列重复显示所属品名 |
| 商品 | 颜色 | 编辑项 | SKU 颜色，仅颜色子行可编辑 |
| 商品 | 预警 | 计算项 | 由预计库存与红线/正常/峰值库存比较得出 |
| 入口 | 需安排 | 编辑项 | 空值按 0；采纳后叠加进预计库存，从而影响预警、缺口量与缺口率 |
| 入口 | 生产中 | 编辑项 | 直接取值 |
| 出口 | 欠货 | 编辑项 | 仅记录展示，不参与任何数量计算 |
| 出口 | 周消耗 | 编辑项 | 备货策略各库存的计算基数 |
| 库存 | 在仓库存 | 编辑项 | 直接取值，参与理论库存与库销比 |
| 库存 | 周转入 | 编辑项 | 直接取值，默认 0；仅记录展示，暂不参与理论库存与预警计算 |
| 库存 | 在途库存 | 导入项/编辑项 | 由导入文件提供，可空（按 0）；参与理论库存计算 |
| 库存 | 理论库存 | 计算项 | 在仓库存 + 在途库存（事实层，不含计划） |
| 库存 | 预计库存 | 计算项 | 理论库存 + 需安排（空按 0）；评估层，预警与缺口的判定基数 |
| 数据反馈 | 缺口量 | 计算项 | 正常库存 − 预计库存；规则缺省时为“缺省”，可为负（负值表示超出正常库存） |
| 数据反馈 | 缺口率 | 计算项 | 缺口量 ÷ 正常库存 × 100%；规则缺省或正常库存为 0 时为空（显示“--”） |
| 数据反馈 | 库销比 | 计算项 | 在仓库存 ÷ 周消耗；周消耗为 0 时为空（显示“--”） |
| 备货策略 | 红线库存 | 计算项 | 周消耗 × 红线系数 |
| 备货策略 | 正常库存 | 计算项 | 周消耗 × 正常系数 |
| 备货策略 | 峰值库存 | 计算项 | 周消耗 × 峰值系数 |
| 备货策略 | 系数 | 计算项 | 红线/正常/峰值系数，规则缺省时显示“缺省” |

数量关系链：

1. 周消耗 × 各系数 → 红线库存、正常库存、峰值库存。
2. 在仓库存 + 在途库存 → 理论库存（在途库存由导入/录入提供，需安排不参与该步）。
3. 理论库存 + 需安排（空按 0）→ 预计库存。
4. 预计库存 与 红线/正常/峰值库存比较 → 四色预警（见第 1 节）。
5. 正常库存 − 预计库存 → 缺口量；缺口量 ÷ 正常库存 → 缺口率。
6. 在仓库存 ÷ 周消耗 → 库销比。

品名父行的汇总规则：

- 只汇总当前可见的子行；需安排空值按 0 累加，其余数值字段在子行均为有效数值时求和，否则显示“缺省”。
- 红线库存、正常库存、峰值库存、预计库存、缺口量仅在子行规则全部可用时求和；父行缺口率、库销比按汇总后的值重新计算。
- 父行不显示预警灯。

数值显示规则：整数原样显示，非整数保留两位小数；规则缺省的数量显示“缺省”，无法计算的比率显示“--”。

## 3. 库存表与配置

- 主表按品名（SPU）分组，品名父行可折叠/展开颜色 SKU 子行；父行展示可见子行的汇总。
- 库存日常操作放在主面板；色彩类别仍随导入维护，热度在独立配置信息页按导入数值判定，两页共享运行时数据。
- 顶部导航左侧为主面板组（主面板、配置信息），右侧为示例数据组（示例面板、示例配置）；示例数据组仅用于对照演示，不作为需求迭代目标。
- 主面板与示例面板结构、计算和交互完全一致，但库存、需安排采纳、撤销状态和采购清单各自独立；“配置信息”页只维护主面板数据，“示例配置”页只维护示例面板数据，两者互不影响。
- 在途库存、理论库存、预计库存的计算口径见第 2 节；“已安排”字段及列已移除。
- “库存”分组依次展示在仓库存、周转入、在途库存、理论库存和预计库存。
- 预设商品的需安排初始为空，空值按 0 计算。
- 预警只以 SKU 的已采纳库存计算，采用色块显示，不在灯旁显示状态文字：
  - 红：预计库存低于红线，紧急补货。
  - 紫：预计库存高于峰值，降低库存。
  - 绿：预计库存位于正常库存的 80% 至 120%（含边界），无需补货。
  - 黄：其他可计算状态，常规补货。
  - 灰：规则缺省，不参与四色筛选。

## 4. 筛选

- 支持品名、颜色关键词筛选，以及按热度/色彩类别查看分类数据。
- 红、黄、绿、紫预警状态可多选；多个预警条件之间为“或”。
- 品名、颜色、分类与预警筛选条件之间为“且”。
- 筛选只影响表格展示；紧急补货清单和库存 Excel 导出仍使用全量 SKU。

## 5. 需安排与补货

- 需安排输入先作为草稿；草稿本身不改变实际库存与统计数据，但会按“理论库存 + 草稿”预览该行在采纳后的预警色。
- 点击“采纳”后写入需安排值，预计库存随之抬高，预警、缺口量与缺口率同步更新；采纳后输入框锁定，按钮变为“撤销”。需安排不写回在途库存。
- 撤销恢复采纳前的数值（原值为空则恢复为空），预计库存与预警同步回落，同时解锁输入框。紧急补货提交同样保存可撤销快照。
- 主表提供紧急补货弹窗，记录新增计划数量；确认后累加到需安排，不覆盖原值。
- 需安排建议值 = max(当前需安排（空按 0）, 0, ⌈正常库存 × 80% − 理论库存⌉)，仅作为输入提示，不自动采纳。

## 6. 本次采购清单与导出

- 主表采纳需安排或紧急补货确认后，将 SKU 同步加入“本次采购清单”；同一 SKU 只保留一行，后续提交更新需安排数。
- 撤销库存变更时同步恢复或移除对应清单记录。
- 清单显示品名、颜色、需安排和实际计划；实际计划初始为空，可填写，且不参与库存计算。
- 清单可导出为 XLSX；表头浅色底、深色字，单元格内容统一居中。
- **待确认：**是否需要将采购清单按具体工厂拆分/分配，以及工厂信息来源和维护方式。

## 7. 主面板 Excel 导入

主面板库存数据以 Excel 导入为准；示例面板不提供导入入口。

### 7.1 导入模板

按“品名 + 颜色”识别 SKU，模板列如下（“导入模板”按钮可直接下载带示例行的模板）：

| 列 | 必填 | 说明 |
|---|---|---|
| 色彩 | 否 | 黑白 / 彩色；留空视为规则缺省 |
| 品名 | 是 | 去除空格后作为 SPU 名称 |
| 颜色 | 是 | SKU 颜色 |
| 生产中 | 否 | 空值按 0 |
| 欠货 | 否 | 空值按 0，仅记录展示 |
| 周消耗 | 否 | 空值按 0，备货策略的计算基数 |
| 在仓库存 | 否 | 空值按 0 |
| 在途库存 | 否 | 空值按 0；参与理论库存计算 |
| 周转入 | 否 | 空值按 0，仅记录展示 |

- 热度不参与导入，导入后按“热度配置”规则计算；文件带“热度”列时预览会提示该列被忽略。
- 需安排不参与导入，继续由面板内的采纳/撤销维护；文件带“需安排”列时预览会提示该列被忽略。
- 理论库存、预计库存、缺口量、缺口率、库销比、红线/正常/峰值库存、系数与预警灯由系统计算，导入文件中的同名列忽略。
- 表头需包含“品名”和“颜色”，可位于前 10 行任意一行；“保存Excel”导出的两行分组表头可直接再次导入。
- 列顺序不限，多余列忽略；数值可带千分位分隔符。

### 7.2 导入行为

- 整表替换：确认后主面板库存行全部替换为导入数据。
- 主面板表格采用滚动虚拟化，只渲染视口内的行，3 万行量级也不会一次性创建大量节点。
- 需安排、撤销快照和本次采购清单按“品名 + 颜色”保留；Excel 中不再存在的 SKU，其需安排与清单记录一并移除。
- 只支持 .xlsx（单个文件不超过 20MB），读取第一张工作表。
- 确认前展示预览：有效行数、忽略的空行数、错误行数及逐行原因；错误行不静默丢弃，修正后可重新导入。
- 错误情形：品名或颜色为空、品名+颜色重复、数值列不是有效数字、色彩不在枚举内。
- 导入结果只保存在页面运行期间，刷新后恢复预设数据。

### 7.3 后续来源表（未实现）

仍计划汇总货盘表、排期表、欠货表、出库表、销售表、库存表等来源，按“品名 + 颜色”生成周数据；来源表模板、列名映射、同 SKU 多行合并方式与重复导入策略待明确。

## 8. 数据与保存范围

- 当前使用模拟库存数据；每个面板（主面板、示例面板）的库存、采购清单、撤销状态和热度配置在页面运行期间各自共享。
- 主面板单次导入可支撑 3 万行以上（实测 3 万行约 1.5 秒可用，滚动与筛选保持流畅）；单文件上限 20MB。
- 配置信息页仍是 Element Plus 常规表格：库存记录超过 500 行时改为扁平分页（每页 60 行），不超过 500 行时保持按品名分组的树形展示。
- 切换主面板、配置信息、示例面板与示例配置不丢失当前运行数据；刷新页面恢复初始示例数据。
- 示例面板与示例配置内的数据固定作为示例，后续需求调整只在主面板与配置信息中实施。
- XLSX 导出为下载副本，不是持久化存储，也不能自动回写系统数据。
