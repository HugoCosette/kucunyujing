# 真实体量滚动导入演示（2 万 SKU × 7 天）

配套口径：[采购下单流程.md](../../功能说明/采购下单流程.md) 3.11「在途对账」。
数据来源：`tools/cleaning/data/` 的 **2026-10-21 真实导出**（产品资料 / 出码率 / 出入库明细 / 库存结存表 / 欠货 / 生产排单），不是随机造数。

---

## 1. 这是什么

`day-01` … `day-07` 每天一个文件夹、6 张分表，模拟「每天早上导入一次、截止昨天的累计快照」。
剧本与 128 个 SKU 的 [滚动导入演示](../滚动导入演示/README.md) 完全一样，只是换成真实体量。

| 项 | 值 |
| --- | --- |
| SKU | 造 20,000，清洗后 **20,006**（+ 6 个场景 SKU） |
| 出入库明细 | 每天 37.9 万 ~ 38.5 万行（真实历史 + 窗口增量） |
| 单日体积 | 约 58 MB（6 张表合计） |
| 7 天合计 | 约 **407 MB**（生成完别忘删，见第 6 节） |
| 历史数据 | 2026-02 ~ 2026-10-21，真实明细原样保留 |
| 回放窗口 | **2026-10-22 ~ 10-28**（7 天） |

**每一天的文件都是「截止当天」的累计快照，不是增量。** 按 01 → 07 顺序导，不能跳、不能倒。

### 导入实测（开发态 localhost）

| 指标 | 实测值 |
| --- | --- |
| day-01 导入（58 MB / 38.5 万行） | 约 3 分钟（含后台压缩快照） |
| 导入后 SKU 数 | 20,006 |
| 快照体积（压缩后） | **2.4 MB** / 份，14 份约 34 MB |
| 预警分布 | 紧急 668 / 常规 187 / 正常 455 / 超库存 2,131 |
| 模式分布 | 滞销 10,072 / 尾货 5,474 / 按量 2,518 / 常规 1,088 / 热销 436 / 专属品 418 |
| 需安排建议 > 0 | 1,420 个 SKU |

对照：直接清洗**真实**的 22,312 个 SKU 是 滞销 12,384 / 尾货 5,455 / 按量 2,496 / 常规 1,076 / 热销 430 / 专属品 471、需安排 > 0 1,366 个 —— 比例基本一致（尾货 / 滞销占大头是业务事实，不是数据造坏了）。

## 2. 和真实数据的差别

- 窗口 7 天里，给 **4,800 个有销量的 SKU 补了 6,925 笔出库**（按各自真实月销量摊），其余 SKU 这 7 天没有出库 —— 真实业务里尾货本来也不是天天卖。
- 追加 **6 个场景 SKU**（场景A品 ~ 场景F品），库存结存、生产排单、生产入库按剧本写。
- **除场景 SKU 外没有任何「生产入库」**：真实业务还没上线这类单据，所以真实 SKU 在窗口期上的排单不会自动归零（口径见 3.11「上线前置条件」）。这正好可以用来观察"没有到仓信号会长什么样"。

## 3. 怎么导入

1. 主面板（需求表）→ 顶部「导入分表」→ 选中 `day-01` 里**全部 6 个文件** → 开始清洗并导入（约 3 分钟，别关页面）。
2. 之后每天导入对应 `day-0N` 的 6 个文件。

文件名关键字（产品资料 / 出码率 / 出入库明细 / 库存结存表 / 欠货 / Scheduling）是自动认领用的，不要改名。

> 20,006 个 SKU 的主面板会明显变卡一点（虚拟列表只渲染可视行），筛选、展开、切页行为与真实数据一致。

## 7. 这份数据怎么生成的

```bash
cd tools/cleaning
node --max-old-space-size=6144 simulate-real-rolling.mjs --skus 20000 --days 7 --check
```

- `--skus N`：要多少个 SKU（只从「清洗后能留下」的 SKU 里挑：公斤单位，或码单位且有出码率）。
- `--days N`：窗口天数；窗口从真实明细的最后一天（2026-10-21）往后接。
- `--history-months N`：只保留最近 N 个自然月的历史。想瘦身用 `--history-months 3`（约 120 MB）；注意砍历史会让「累积销量」变小、评分里的进销比偏大。
- `--check`：生成后用真实清洗引擎跑一遍 day-01 / 最后一天，打印行数、场景 SKU 的在仓 / 在途 / 理论 / 预计与模式分布。
- `--out <dir>` / `--keep`：输出目录 / 保留旧目录。
