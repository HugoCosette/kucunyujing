# 数据规则


预计库存=需安排+生产中+在仓库存
缺口量=正常库存-预计库存
缺口率=缺口量/正常库存
备货策略库存数=周消耗*对应系数
紧急状态 = 详见 亮灯规则.md
欠货 = 暂时全0

主表中编辑需安排时，输入值先作为草稿预览，不进入上述预计库存或预警计算；点击“采纳”后才更新实际需安排，并按原公式和灯亮规则刷新计算。



0，预设值，可点击修改，需安排为空（按0参与计算）、生产中1000、在仓库存3000、周消耗1000，欠货0
1，信息中，先选择备货类型（热销/常规），再选择色彩类别（黑白/彩色）
2，根据库存规格，按备货类型和色彩类别读取红线、正常、峰值系数；不再使用 SS、S、A 等级
3，计算 红线库存、正常库存、峰值库存，其中 对应库存=周消耗*对应系数
4，缺口量=缺口量/正常库存，缺口率=缺口量/正常库存，库销比=在仓库存/周消耗
5，预计库存= 需安排+生产中+ 在仓库存
