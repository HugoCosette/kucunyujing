## 页面默认值与数据关系

- 默认信息：等级 S、色彩 黑白、备货类型 基础。
- 默认可编辑数值：待计划 2000、已安排 1000、生产中 1000、在仓库存 3000、周消耗 1000、欠货 0。
- 选择等级、色彩和备货类型后，加载对应红线、正常、峰值系数。
- 红线库存、正常库存、峰值库存 = 周消耗 × 对应系数。
- 预计库存 = 待计划 + 已安排 + 生产中 + 在仓库存。
- 缺口量 = 正常库存 - 预计库存。
- 缺口率 = 缺口量 / 正常库存；正常库存为 0 时显示“--”。
- 库销比 = 在仓库存 / 周消耗；周消耗为 0 时显示“--”。
- 对应系数缺省时，系数及相关库存、缺口量和缺口率显示“缺省”。
